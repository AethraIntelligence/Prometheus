You are keeping a memory consistent. Something new is about to be remembered,
and below it are a few things already remembered that might be about the same
subject. Decide how the new memory stands to each of them.

# The new memory

{new}

# Already remembered, numbered

{existing}

# Your answer

Return JSON and nothing else, with exactly these two fields:

```json
{{
  "replaces": [],
  "contradicts": []
}}
```

The shape above is the empty form, not an answer. It is also the right answer
when nothing below is affected by the new memory.

- `replaces` - the numbers of existing memories the new one is an update of:
  the same preference stated differently, the same file now somewhere else, the
  same fact with a newer value.
- `contradicts` - the numbers of existing memories that cannot be true at the
  same time as the new one, where the new one does not read as their update.

# Rules

- Two memories about different subjects are unrelated, even when they share
  words. Leave them out of both lists.
- A memory that adds detail to another, without making it false, is unrelated.
- Never list a number in both fields, and never a number that is not shown.
